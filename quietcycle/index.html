Haptic shortcut test

Experimental · one chime + one native vibration through Apple Shortcuts. This does not add automatic haptics to the timer.

Tapping this button directly plays only a chime. To request vibration, run the shortcut from Safari’s Share menu after setting it up below.

Set up the iPhone shortcut
  1. Open this page in Safari. Pause the timer, then tap Haptic shortcut test once to activate audio. Wait for the sound to finish.
  2. In Apple Shortcuts, create Quiet Cycle Haptic Test. In its details, enable Show in Share Sheet and accept Safari Web Pages.
  3. Add Run JavaScript on Web Page. Set its webpage input to Shortcut Input. Paste the code below into its script field.
  4. Add If: JavaScript Result is PLAYING. Inside that branch add Vibrate Device. Inside Otherwise, add Show Alert with JavaScript Result. End If.
  5. If Shortcuts asks, enable Allow Running Scripts in its Advanced settings and allow the shortcut to run on this page.
  6. Return to this page in Safari, then choose Share → Quiet Cycle Haptic Test.

Expected: one warm chime followed closely by a vibration. The script confirms that audio playback started before returning PLAYING. It cannot verify that sound reached your speaker or that vibration occurred. Timing, vibration length, and Safari share-sheet behavior still need an on-device test. Keep your screen awake for this experiment.
